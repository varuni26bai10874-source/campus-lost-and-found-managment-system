w#Project Statement
##Problem Statement
Students can loose personal belongings on campus, such as ID cards,books,bags,stationary,electronic devices, and other items .
Without a centralized system , it can be difficult for students to report lost or found items and find information about items that have been reported.
The campus Lost and Found Management System provides a simple digital solution for managing lost and found items on campus
## Scope of the project
The projectfocuses on providing a basic lost and found management system for campus students.

The system allows users to:

- Register an account
- Login to the system
- Report lost items
- Report found items
- View reported items
- Search for items
- Claim available items
- Logout from the system

The current version is a Python-based console application.

## Target Users

The main target users are:

- College students
- Campus users who lose items
- Campus users who find items

## High-Level Features
### 1. User Registration

Students can create an account using their name, student ID, and password.

### 2. User Login

Registered students can login using their student ID and password.

### 3. Report Lost or Found Item

Users can report an item by entering information such as:

- Item type
- Item name
- Category
- Location
- Date
- Description

### 4. View Items

Users can view all reported lost and found items.

### 5. Search Items
Users can search for items using the item name or category.

### 6. Claim Item

Users can select an available item and mark it as claimed.

### 7. Logout

Users can safely return to the main menu by logging out.
