Campus Lost and Found Management System

## Overview

The Campus Lost and Found Management System is a Python-based application designed to help students report and find lost or found items on campus.

The system provides a simple centralized way for students to report items, view reported items, search for items, and claim items.

## Features

- User registration
- User login
- Report lost items
- Report found items
- View all reported items
- Search for items by name or category
- Claim available items
- Input validation
- Logout functionality

## Technologies and Tools Used

- Python
- Python IDLE
- Git
- GitHub
